# VoxHearth

**Dictation that stays home.**

VoxHearth is an open-source macOS dictation app designed to run entirely on
your Mac. The release build includes its speech model and has no online mode,
account, telemetry, or update checker.

The privacy-focused application is being rebuilt from the TypeWhisper v1.5.1
codebase. See [UPSTREAM.md](UPSTREAM.md) for provenance.

## Status

The `main` branch is the release branch for VoxHearth 0.1.0. Until the first
signed release is published, build and verification instructions live in
`scripts/local-check.sh`.
